# Hobby
Repository containing many different mini-projects, mainly for experimenting with AI and computer science as a fun hobby.

# Rules
1. **Freedom from corporate rigor** - No need to force docstrings, type hints, or perfect architecture unless absolutely necessary (while keeping Rule #4 in mind).
2. **The process over the outcome** - Spending 5 hours without visible results is completely fine. The main goal is simply to code and enjoy the process.
3. **Focus on delivery** - Functionality beats perfection. At the end of the day, the project just needs to work.
4. **Pause, don't abandon** - Shelving a project for a longer period to jump into a new one is totally okay, as long as there is a genuine intention to come back to it.

# Naming
Each folder in the main branch is a separate mini-project. Folder names should follow a `[Technology]-[Description]` format (e.g., `PyTorch-InstanceSegmentation`).
